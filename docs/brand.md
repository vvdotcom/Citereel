# Citereel

Public product name: **Citereel** (pronounced “sight-reel”).

The name combines citations with video reels: product videos connected to their source evidence.

The custom vector icon combines an orange C-shaped source bracket with a white play symbol on AWS-inspired navy. The same SVG is used for the website, workspace and browser-tab icon. Preserve its proportions and use the existing Inter typography for the wordmark.

- Icon: `public/brand/citereel.svg`
- Orange: `#ff9900`
- Navy: `#182534`
- White: `#ffffff`

This is a public-facing rebrand, not an infrastructure migration. Existing `Launchpad` folder names, AWS resource names, environment variables, API packages, session cookies and historical verification receipts remain unchanged for compatibility. Product names inside generated customer videos remain the customer's brand.

The name and icon have not undergone trademark clearance; domain availability has not been verified.
