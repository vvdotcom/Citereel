## Four AWS-backed homepage modes

All four samples were regenerated through the local Launchpad API, durable worker,
reviewed storyboard approval, browser capture, Polly and media QA. The Northstar
site is an owned demonstration, not a real customer. Each export is approximately
30 seconds; landscape modes are 2560×1440 and Shorts is 1080×1920.

| Mode | Job | Planning | Narration |
| --- | --- | --- | --- |
| Presentation | `lp_e33fa1b90df444e6` | Strands + Bedrock | Amazon Polly |
| Product demo | `lp_82539eb5a2524c07` | Strands + Bedrock | Amazon Polly |
| Spotlight | `lp_0140a59405a740e2` | Strands + Bedrock | Amazon Polly |
| Short | `lp_ac9ccef671de4d79` | Strands + Bedrock | Amazon Polly |

`artifacts/verification/aws-four-modes/*-receipt.json` records model tokens, Strands
tool traces, real capture events and the voice provider for every scene. Staging
checks the downloaded MP4 SHA-256 and size before replacing public samples, and
backs up previous public media. Exports remain available in the workspace for
review; they are not marked as human-approved final exports.

To reproduce against the running app (incurs AWS usage):

```powershell
.venv\Scripts\python scripts/generate_aws_examples.py create
.venv\Scripts\python scripts/generate_aws_examples.py plans
# Inspect each *-review.json before approving its claims and storyboard.
.venv\Scripts\python scripts/generate_aws_examples.py approve
.venv\Scripts\python scripts/generate_aws_examples.py stage
```

The script resumes its saved job IDs and respects the two-active-job queue limit.
Polly is the default on all platforms. Offline Windows narration and deterministic
planning require explicit test configuration; neither is a live failure fallback.
`tests/test_public_aws_examples.py` guards the AWS provider claims against the
published files. The older verification sections below describe historical runs.
